# 이미지 뷰어 (안드로이드)

사이트를 앱 안의 브라우저로 열고, 그 페이지의 이미지를 한 장씩 넘겨 보는 앱입니다.

## 쓰는 법

1. 위쪽 주소창에 사이트 주소를 입력하고 키보드의 이동 버튼을 누릅니다. 검색어를 넣으면 구글 검색이 열려요.
2. 평소 브라우저처럼 로그인, 스크롤, 링크 이동을 하면 됩니다. 왼쪽 ← 버튼은 뒤로 가기예요.
3. 주황색 이미지 버튼을 누르면 지금 화면에 보이는 이미지부터 뷰어가 열립니다.

| 동작 | 결과 |
|---|---|
| 화면 오른쪽 탭 | 다음 이미지 |
| 화면 왼쪽 탭 | 이전 이미지 |
| 화면 가운데 탭 | 메뉴 표시/숨김 (슬라이더로 이동, 맞춤 모드, 넘김 방향) |
| 좌우로 밀기 | 다음/이전 |
| 두 손가락 벌리기 | 확대 |
| 볼륨 아래/위 키 | 다음/이전 |
| 뒤로가기 | 뷰어 닫기 (마지막으로 본 이미지 위치로 페이지가 이동) |

- 웹툰처럼 세로로 아주 긴 이미지는 자동으로 가로 폭에 맞추고, 오른쪽을 탭하면 아래로 내려가다가 끝에서 다음 이미지로 넘어갑니다.
- 만화처럼 오른쪽에서 왼쪽으로 읽을 때는 메뉴에서 "넘김: 왼쪽이 다음"으로 바꾸세요.
- 페이지의 이미지를 길게 누르면 그 이미지부터 보여줍니다.
- 이미지 버튼을 길게 누르거나 ⋮ 메뉴의 "끝까지 불러온 뒤 보기"를 쓰면, 스크롤해야만 나타나는 이미지까지 모두 모읍니다.
- 크롬 등에서 "공유 → 이미지 뷰어"를 누르면 그 링크가 바로 열립니다.

## 찾아내는 이미지

- 일반 `<img>`. srcset 이 있으면 가장 큰 해상도를 고릅니다.
- 지연 로딩 이미지 (`data-src`, `data-original`, `data-lazy-src` 등)
- 썸네일이 원본 파일에 링크돼 있으면 원본
- `<picture>`, CSS 배경 이미지, 이미지 파일로 바로 걸린 링크
- 같은 사이트의 iframe 안쪽

아이콘·로고처럼 작은 이미지는 기본으로 빠집니다. ⋮ 메뉴에서 "작은 이미지도 포함"을 켜면 들어갑니다.

## 설치 / 빌드

**바로 설치:** 함께 받은 `ImageViewer.apk` 를 폰에 옮겨 열면 됩니다. "출처를 알 수 없는 앱" 설치 허용을 물으면 허용하세요.

**GitHub 로 빌드:** 이 폴더를 그대로 새 GitHub 저장소에 올리면 Actions 가 자동으로 APK 를 만듭니다.
Actions 탭 → 최근 실행 → Artifacts 의 `ImageViewer-apk` 를 받으면 됩니다.

**Android Studio:** File → Open 으로 이 폴더를 열고 ▶ Run 을 누릅니다.

## 파일 구성

- `app/src/main/java/.../MainActivity.java` — 브라우저, 툴바, 뷰어 열기/닫기, 볼륨키
- `app/src/main/assets/extract.js` — 페이지에서 이미지 주소를 모으는 스크립트
- `app/src/main/assets/viewer.html` — 한 장씩 보여주는 뷰어 화면 (탭/스와이프/확대)

## 알아둘 점

- 이미지를 캔버스로 그리거나 강하게 암호화하는 일부 사이트는 이미지를 찾지 못할 수 있어요.
- 사이트 이용약관과 저작권은 지켜서 개인 열람용으로 써 주세요.
